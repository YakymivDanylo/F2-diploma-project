# Календарний план

Структура строго реплікує Лист завдання. Таблиця реалізована як база даних Obsidian Bases: кожен етап — окремий запис у папці `Calendar-Plan/` з типізованими полями. Термін виконання та статус залишаються незаповненими до затвердження теми.

![[Календарний план.base]]

## Структура полів

| Графа | Властивість | Тип |
| --- | --- | --- |
| № з/п | `stage_no` | Number |
| Назва етапу кваліфікаційної роботи | `stage_name` | Text |
| Термін виконання етапів проєкту | `deadline` | Date (порожнє) |
| Примітка / Статус виконання | `status` | Вибір: To Do / In Progress / Done |

Пов'язано: [[00-Dashboard]], [[01-Passport]]
