## Матриця нефункціональних вимог (NFRs)

Конфігурація вимірювань: 4 вузли (n = 4, f = 1), docker-compose. Повна версія — [1_analysis.md](1_analysis.md#153-нефункціональні-вимоги-nfrs).

| Категорія | Вимога | Цільова метрика |
| --- | --- | --- |
| Продуктивність | Верифікація `GET /documents/{hash}` | p95 ≤ 200 мс при 200 RPS на вузол |
| Продуктивність | Фіналізація блоку PBFT | ≤ 2 с (n = 4, f = 1) |
| Масштабованість | Реєстрація записів | ≥ 50 записів/с, до 256 записів у блоці |
| Безпека | Примітиви та транспорт | SHA-256, ECDSA P-256, TLS 1.3 |
| Безпека | Автентифікація запису | Лише підпис зареєстрованого емітента (інакше 403) |
| Комплаєнс | GDPR (ст. 5, 25) | У ланцюгу лише хеш, підпис, ідентифікатор емітента |
| Надійність | Fault Tolerance | PBFT: f ≤ ⌊(n − 1)/3⌋ збійних вузлів |
| Надійність | Стійкість до атак | Backdating виявляється у 100 % тестів; Sybil-вузли без реєстрації не впливають на консенсус |
| Інфраструктура | Контейнери та образи | Docker без root; Trivy: 0 CRITICAL |
| Супроводжуваність | Якість коду | Покриття ядра тестами ≥ 80 % |
