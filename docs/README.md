# Пояснювальна записка — навігація

Кваліфікаційна робота бакалавра, спеціальність F2 (121) «Інженерія програмного забезпечення».

**Тема:** Децентралізована система верифікації документів на основі власної реалізації блокчейн-технології.

Документація ведеться за методологією Docs-as-Code: кожен розділ пояснювальної записки — окремий Markdown-файл у каталозі `docs/`.
